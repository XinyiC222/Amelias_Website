This website is mainly written in .jsx and .css files. This is my personal website/portfolio that I made for fun! Feel free to fork it but please credit me! Thank you.

## Built With
- React.js
- Node.js
- Vite
- VsCode
- CSS

## Features
- SVG background
- music player
- Styled with React and CSS
- .jsx files
- stickers!
- buttons and icons


## How to Run it
1. clone the project(prerequisites: ```node.js``` and ```git```)
2. Install: ```npm install```
3. In project directory: ```npm start```

## To Edit
go into ```src/``` to view all the files you can make changes to!
